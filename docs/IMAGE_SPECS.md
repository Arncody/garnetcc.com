# Garnet image specifications

## Hero background
- Desktop: 2560×1440 px (16:9), fallback 1920×1080 px.
- Tablet: 2048×1365 px (3:2) if a dedicated crop is needed.
- Mobile: 1440×1920 px (3:4) preferred for portrait composition; keep the main subject near the visual center.
- Hero video: MP4/H.264 or WebM, 1920×1080 px, 24–30 fps, target ≤15 MB.

## Project cards
- Main desktop card: 1600×1000 px (8:5).
- Mobile card: 1200×900 px (4:3).
- Project detail hero: 2200×1400 px (11:7).

## Blog cover
- 1600×1000 px (8:5).

## Service images/icons
- Service image: 1200×900 px (4:3).
- Icon: SVG preferred; raster fallback 256×256 px transparent PNG.

## Logo
- SVG preferred.
- Raster fallback: 1000×1000 px transparent PNG, with generous transparent padding.
