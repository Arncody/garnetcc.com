# V12 changes

- Mobile hamburger is borderless and rendered as three minimal lines.
- Header uses a lighter white glass surface; opacity/blur/border/text/CTA are editable in Site Theme.
- Logo and brand area are larger and configurable for desktop/mobile.
- Project-detail consultation CTA opens the shared consultation modal instead of navigating home.
- Project hover layers receive explicit z-index/stacking fixes to prevent being painted under neighboring content.
- Site Theme now exposes advanced controls for header, CTA colors, glass buttons, modal, hero overlay, footer, logo sizing, and typography.
- Image/video production dimensions are documented in `docs/IMAGE_SPECS.md`.
- Django Admin remains on the default Django admin visual system.
