# Garnet Compact Luxury V6

## UX goals
- Home is condensed into three visual zones: Hero, selected work/services, portfolio/journal.
- Mobile Hero uses compact action buttons for ongoing projects, completed portfolio, and company catalog.
- Consultation form is removed from page flow and opens as a light white-glass dialog.
- Blog is available from header/footer and is bilingual.
- Company catalog is uploaded/replaced from Django Admin.

## Media guidance
- Hero image: 1920x1080 or 2560x1440, 16:9.
- Hero video: MP4/H.264 or WebM, 1920x1080, target <=15MB.
- Project cards: 1600x1100 or 4:3/3:2 source; crop is handled by CSS.
- Blog cover: 1600x1000 minimum.
